BUILD THE APK (no Android Studio needed)
1. Create a free GitHub account and a new empty repository.
2. Upload ALL files and folders from this project (including the hidden .github folder) to it.
3. Open the repo > Actions tab > "Build APK" > wait about 5 minutes for the green tick.
4. Open the finished run > Artifacts > download PrintPro-apk, unzip it, install app-debug.apk on your phone (allow "install unknown apps").

PRINTER SETUP (once, on the phone)
Settings > Connected devices > Connection preferences > Printing > Default Print Service > turn on, then
tap Add printer and choose your Wi-Fi printer, or enter its IP address for an Ethernet-connected printer.
